# ✅ Kanban To-Do App

A **Kanban-style task manager** written in **vanilla JavaScript**. Tasks move through **To Do → Started → Completed** columns using drag and drop.

🔗 **Live demo:** https://sonu2002.github.io/kanban-todo-app/

## ✨ Features
- Add, edit and delete tasks
- **Drag & drop** tasks between the *To Do*, *Started* and *Completed* columns
- Empty-state placeholder when there are no tasks
- No frameworks: DOM manipulation and HTML5 Drag & Drop API only

## 🛠️ Tech stack
`HTML5` · `CSS3` · `JavaScript (ES6)` · `Font Awesome`

## 🚀 Run locally
Open `index.html` in your browser.
